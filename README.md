# micks.win

**A Cabinet of Infinite Rooms** — twenty-four living worlds, rendered live in the
browser, ranked by how hard they hold the eye.

Nothing on this page is a video. Every pixel is computed on your GPU, in front of
you, sixty times a second: raymarched singularities, a real Navier–Stokes fluid,
Schwarzschild geodesics, sixty thousand particles riding a curl-noise river,
strange attractors, op-art interference, a mountain range that has never existed
before and never will again.

The cabinet turns itself over every 21 seconds. You can stop it, steer it, or
walk straight to any room.

## Running it

It is a static site — no build step, no dependencies.

```bash
python3 -m http.server 3000      # or: npx serve .
# open http://localhost:3000
```

Requires **WebGL2** (any current Chrome, Edge, Firefox or Safari with hardware
acceleration). Resolution scales itself to keep the frame rate honest.

| `AAAA` | `@` | `2606:50c0:8000::153` |
| `AAAA` | `@` | `2606:50c0:8001::153` |
| `AAAA` | `@` | `2606:50c0:8002::153` |
| `AAAA` | `@` | `2606:50c0:8003::153` |

Then add a `CNAME` file containing `micks.win` at the repository root (or set
the custom domain in **Settings → Pages**) and switch **Enforce HTTPS** on once
the certificate has provisioned. Do it in that order — setting the custom domain
before the DNS exists makes the `github.io` address redirect to a host that does
not resolve yet.

## How it is put together

```
index.html
assets/css/style.css          the interface: glass, hairlines, the rail, the gallery
assets/js/glsl-prelude.js     shared GLSL (noise, fbm, palettes, sdf, tonemap)
assets/js/gl.js               tiny WebGL2 helper: cached programs, ping-pong targets
assets/js/engine.js           the cycling engine, transitions, adaptive resolution
assets/js/designs/*.js        the worlds
```

Two kinds of world share one page:

* **`gl`** — a single fragment shader run over a full-screen triangle. The engine
  feeds it `uRes`, `uTime`, `uFade`, `uMouse`, `uEnergy` and a per-visit `uRand`.
* **`glx`** — multi-pass: the fluid and the particle system own their own
  floating-point targets.
* **`2d`** — canvas worlds for the things points, strokes and gradients do best.

Only the world on stage runs. The next one is compiled quietly before it is
needed, and each cut crossfades through a snapshot of the frame before it.

## Notes

* Respects `prefers-reduced-motion` (no grain, no reveal blur, no pulsing orb).
* A world that fails to compile is skipped rather than shown as a black screen.
* Resolution adapts between 50% and 100% to hold ~60fps, under a 1.9M-pixel budget.
